# Frontend (React + Webpack)

Клиент для LMS: данные курсов, уроков, заданий и прогресса загружаются с **Django REST API**. Статический блог остаётся в `src/data/blogs.json`.

## Настройка

1. Скопируйте `.env.example` в `.env`.
2. Укажите URL бэкенда (без завершающего `/`):

```env
API_BASE_URL=http://127.0.0.1:8000
```

3. На стороне Django в `CORS_ALLOWED_ORIGINS` должен быть origin фронтенда (например `http://localhost:4000` для `npm start`).

## Команды

```bash
npm install
npm start          # dev-сервер (см. server.js / порт в проекте)
npm run build
npm test
```

## Маршруты

| Путь | Описание |
|------|----------|
| `/` | Главная |
| `/catalog` | Список курсов (API) |
| `/course/:id` | Уроки курса (требуется вход) |
| `/lesson/:id` | Урок и задания (требуется вход) |
| `/profile` | Профиль и прогресс (API) |
| `/blog` | Статичный блог |
| `/auth` | Вход / регистрация |

## Авторизация

Используется заголовок `Authorization: Token <token>`. Токен хранится в `localStorage` под ключом `auth_token`.

Регистрация и вход соответствуют полям бэкенда: **имя пользователя** (`username`) и пароль (минимум 8 символов, как в Django).

## Задания типа `test`

В поле `question` первая строка — текст вопроса, следующие строки — варианты ответов (по одному на строку). Поле `correct_answer` на сервере должно **точно совпадать** с текстом выбранного варианта (после `trim`).

## E2E (Cypress)

Тесты используют `cy.intercept` для API и не требуют запущенного бэкенда. Перед прогоном поднимите фронт на порту из `cypress.config.ts` (`baseUrl`, по умолчанию `http://localhost:4000`).
